# Mapa Interativo

Mapa interativo responsivo desenvolvido com **HTML, CSS e JavaScript**, utilizando **Leaflet.js** e **OpenStreetMap** para exibir localizações de forma dinâmica.

##  Funcionalidades

- 🔎 Pesquisa de cidades
- 📍 Visualização de localizações no mapa
- 🗺️ Mapa interativo e dinâmico
- 📱 Interface responsiva
- 🌐 Integração com OpenStreetMap
- ⚡ Atualização das localizações em tempo real

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap

##  Objetivo

Projeto desenvolvido durante meus estudos para praticar JavaScript, consumo de APIs, integração com mapas, manipulação do DOM e desenvolvimento de interfaces responsivas**.
